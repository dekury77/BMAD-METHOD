## 기본 에이전트

이 페이지는 BMad Method와 함께 설치되는 기본 BMM (Agile suite) 에이전트 목록과 각 에이전트의 스킬 ID, 메뉴 트리거, 주요 워크플로우를 설명합니다. 각 에이전트는 스킬로 호출됩니다.

## 참고 사항

- 각 에이전트는 설치 도구가 생성한 스킬로 사용할 수 있습니다. 스킬 ID(예: `bmad-dev`)를 사용하여 에이전트를 호출합니다.
- 트리거는 각 에이전트 메뉴에 표시되는 짧은 메뉴 코드(예: `CP`)와 퍼지 매칭 항목입니다.
- QA 테스트 생성은 개발자 에이전트를 통해 사용할 수 있는 `bmad-qa-generate-e2e-tests` 워크플로우 스킬이 담당합니다. 전체 Test Architect (TEA)는 별도 모듈로 제공됩니다.

## 트리거 유형

에이전트 메뉴 트리거는 두 가지 호출 방식을 사용합니다. 트리거 유형을 알면 적절한 입력을 제공하는 데 도움이 됩니다.

### 워크플로우 트리거 (인자 불필요)

대부분의 트리거는 구조화된 워크플로우 파일을 불러옵니다. 트리거 코드를 입력하면 에이전트가 워크플로우를 시작하고, 각 단계에서 입력을 요청합니다.

예시: `CP` (PRD 생성), `DS` (개발 스토리), `CA` (아키텍처 생성), `QD` (퀵 데브)

### 대화형 트리거 (인자 필요)

일부 트리거는 구조화된 워크플로우 대신 자유 형식의 대화를 시작합니다. 트리거 코드와 함께 원하는 내용을 직접 설명해야 합니다.

| 에이전트 | 트리거 | 제공할 내용 |
| --- | --- | --- |
| 테크니컬 라이터 (Paige) | `WD` | 작성할 문서에 대한 설명 |
| 테크니컬 라이터 (Paige) | `US` | 표준에 추가할 선호 사항이나 규칙 |
| 테크니컬 라이터 (Paige) | `MG` | 다이어그램 설명과 유형 (시퀀스, 플로우차트 등) |
| 테크니컬 라이터 (Paige) | `VD` | 검증할 문서와 중점 확인 영역 |
| 테크니컬 라이터 (Paige) | `EC` | 설명할 개념 이름 |

**예시:**

```text
WD Write a deployment guide for our Docker setup
MG Create a sequence diagram showing the auth flow
EC Explain how the module system works
```
