BMad는 설치 시 선택하는 공식 모듈을 통해 기능을 확장합니다. 이 추가 모듈은 내장 코어와 BMM (Agile suite)을 넘어 특정 도메인에 특화된 에이전트, 워크플로우, 태스크를 제공합니다.

:::tip[모듈 설치하기]
`npx bmad-method install`을 실행하고 원하는 모듈을 선택하세요. 설치 도구가 다운로드, 설정, IDE 통합을 자동으로 처리합니다.
:::

## BMad Builder

가이드형 지원으로 커스텀 에이전트, 워크플로우, 도메인별 모듈을 생성합니다. BMad Builder는 프레임워크 자체를 확장하기 위한 메타 모듈입니다.

- **코드:** `bmb`
- **npm:** [`bmad-builder`](https://www.npmjs.com/package/bmad-builder)
- **GitHub:** [bmad-code-org/bmad-builder](https://github.com/bmad-code-org/bmad-builder)

**제공 기능:**

- Agent Builder — 커스텀 전문성과 도구 접근 권한을 가진 특화된 AI 에이전트 생성
- Workflow Builder — 단계와 의사결정 지점이 있는 구조화된 프로세스 설계
- Module Builder — 에이전트와 워크플로우를 공유 가능하고 배포 가능한 모듈로 패키징
- YAML 설정과 npm 배포 지원을 포함한 인터랙티브 설정

## Creative Intelligence Suite

초기 개발 단계의 구조적 창의성, 아이데이션, 혁신을 위한 AI 기반 도구입니다. 검증된 프레임워크를 활용하여 브레인스토밍, 디자인 씽킹, 문제 해결을 지원하는 여러 에이전트를 제공합니다.

- **코드:** `cis`
- **npm:** [`bmad-creative-intelligence-suite`](https://www.npmjs.com/package/bmad-creative-intelligence-suite)
- **GitHub:** [bmad-code-org/bmad-module-creative-intelligence-suite](https://github.com/bmad-code-org/bmad-module-creative-intelligence-suite)

**제공 기능:**

- Innovation Strategist, Design Thinking Coach, Brainstorming Coach 에이전트
- 체계적 사고와 측면적 사고를 위한 Problem Solver, Creative Problem Solver
- 내러티브와 피치를 위한 Storyteller, Presentation Master
- SCAMPER, 역 브레인스토밍, 문제 재정의를 포함한 아이데이션 프레임워크

## Game Dev Studio

Unity, Unreal, Godot, 커스텀 엔진에 맞게 조정된 구조화된 게임 개발 워크플로우입니다. Quick Flow를 통한 빠른 프로토타이핑과 에픽 기반 스프린트를 통한 본격적인 제작을 모두 지원합니다.

- **코드:** `gds`
- **npm:** [`bmad-game-dev-studio`](https://www.npmjs.com/package/bmad-game-dev-studio)
- **GitHub:** [bmad-code-org/bmad-module-game-dev-studio](https://github.com/bmad-code-org/bmad-module-game-dev-studio)

**제공 기능:**

- 게임 설계 문서(GDD) 생성 워크플로우
- 빠른 프로토타이핑을 위한 Quick Dev 모드
- 캐릭터, 대화, 세계관을 위한 내러티브 디자인 지원
- 엔진별 아키텍처 가이드를 포함한 21가지 이상의 게임 유형 지원

## Test Architect (TEA)

전문 에이전트(Murat)와 9개의 구조화된 워크플로우를 통한 엔터프라이즈급 테스트 전략, 자동화 가이드, 릴리즈 게이트 결정 지원입니다. TEA는 리스크 기반 우선순위 지정과 요구사항 추적성으로 내장 QA 에이전트를 훨씬 뛰어넘습니다.

- **코드:** `tea`
- **npm:** [`bmad-method-test-architecture-enterprise`](https://www.npmjs.com/package/bmad-method-test-architecture-enterprise)
- **GitHub:** [bmad-code-org/bmad-method-test-architecture-enterprise](https://github.com/bmad-code-org/bmad-method-test-architecture-enterprise)

**제공 기능:**

- Murat 에이전트 (마스터 테스트 아키텍트 및 품질 어드바이저)
- 테스트 설계, ATDD, 자동화, 테스트 리뷰, 추적성을 위한 워크플로우
- NFR 평가, CI 설정, 프레임워크 스캐폴딩
- Playwright Utils 및 MCP 통합 옵션이 포함된 P0-P3 우선순위 지정
